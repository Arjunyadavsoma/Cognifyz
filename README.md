## 🎯 Internship Tasks

### ✅ **Level 1: Beginner Python Projects**
| Task No. | Task Name | Description |
|----------|-----------|-------------|
| 1 | **String Reversal** | Reverses a given string. |
| 2 | **Temperature Converter** | Converts temperatures between Celsius and Fahrenheit. |
| 3 | **Email Validator** | Validates email format using string and regex. |
| 4 | **Calculator** | Performs basic arithmetic operations. |
| 5 | **Palindrome Checker** | Checks whether a string is a palindrome. |

### 🔁 **Level 2: Intermediate Python Challenges**
| Task No. | Task Name | Description |
|----------|-----------|-------------|
| 1 | **Guessing Game** | Guess a number between 1–100 with feedback. |
| 2 | **Number Guesser** | User guesses a random number within a given range. |
| 3 | **Password Strength Checker** | Checks password complexity. |
| 4 | **Fibonacci Generator** | Generates Fibonacci sequence for N terms. |
| 5 | **File Manipulation** | Reads a file and counts word occurrences. |

### 🚀 **Level 3: Advanced Python Projects**
| Task No. | Task Name | Description |
|----------|-----------|-------------|
| 1 | **Web Scraper** | Extracts data from websites using BeautifulSoup. |
| 2 | **Data Visualization Tool** | Generates charts from datasets using Seaborn and Matplotlib. |
| 3 | **Task Automation** | Automates a repetitive task using Python scripts. |
